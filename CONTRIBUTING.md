# Contributing

Thanks for helping improve Ultimate Kotlin Language.

## Lesson guidelines
- Explain concepts in your own words and keep the learning path beginner-friendly.
- Include small, runnable Kotlin examples where practical.
- Add exercises that test understanding rather than memorization.
- Prefer idiomatic Kotlin and explain trade-offs where useful.
- Link to official Kotlin documentation for deeper reading.
- Do not copy large sections of third-party documentation.

## Suggested lesson structure
1. Learning objectives
2. Explanation and key concepts
3. Example walkthrough
4. Common mistakes
5. Exercises
6. Further reading

## Pull requests
Use a descriptive title, summarize the change, and verify examples compile when practical.
