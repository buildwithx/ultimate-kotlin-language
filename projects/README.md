# Kotlin Practice Projects

Build these projects in order. Keep each project in its own directory or IDE project, write a short README, and commit progress regularly.

## 1. Number Guessing Game — beginner
Generate a random number, accept guesses, validate input, and give higher/lower hints. Stretch goals: attempt limit, replay, difficulty levels.

## 2. Console Task Manager — beginner/intermediate
Support adding, listing, completing, and deleting tasks. Model each task with a data class. Stretch goals: filter by status and persist data to a file.

## 3. Expense Tracker — intermediate
Record expenses with category, amount, date, and note. Show totals by category and a monthly summary. Validate user input and separate domain logic from console I/O.

## 4. Library Catalog — intermediate
Create books and members, implement borrowing/returning, and prevent invalid states. Add tests for core rules.

## 5. Capstone — advanced
Choose a problem you care about. Include a clear README, meaningful domain model, error handling, automated tests, and an explanation of design choices.
