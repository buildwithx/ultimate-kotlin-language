# Learning Path

## How to study
1. Follow lessons in numeric order.
2. Type every example yourself and predict its output before running it.
3. Complete the exercises without copying a solution.
4. Explain each concept in your own words.
5. Revisit a topic after using it in a project.

## Milestones
- **Beginner:** modules 00–06 and Number Guessing Game.
- **Core Kotlin:** modules 07–13 and Console Task Manager.
- **Practical JVM:** modules 14–18 and Expense Tracker.
- **Advanced perspective:** modules 19–22 and a capstone.

## Prerequisites
No prior programming experience is required. Familiarity with a terminal helps, but an IDE can run the first lessons. Coroutines and Multiplatform lessons introduce platform/library prerequisites explicitly.
