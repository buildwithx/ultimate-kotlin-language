# Learning Path

## How to study
1. Follow lessons in numeric order.
2. Type examples yourself and predict output before running.
3. Complete exercises without copying a solution.
4. Explain each concept in your own words.
5. Revisit topics while building projects.

## Milestones
- **Beginner:** modules 00–06 and Number Guessing Game.
- **Core Kotlin:** modules 07–13 and Console Task Manager.
- **Practical JVM:** modules 14–18 and Expense Tracker.
- **Advanced perspective:** modules 19–22 and a capstone.

No prior programming experience is required. Coroutines and Multiplatform lessons note extra dependencies or platform setup where needed.
